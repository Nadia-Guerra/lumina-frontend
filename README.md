# Lumina - Aplicación web para reseñas de productos de maquillaje y recomendaciones de estilos

[![Deploy](https://img.shields.io/badge/Deploy-Vercel-black?logo=vercel)](https://lumina-front-blond.vercel.app/)

## Planteamiento
La falta de reseñas verídicas acerca de los distintos productos de belleza que se encuentran en el mercado dificultan una selección óptima para uso personal. Asimismo, muchas personas que desean empezar a aprender un estilo de maquillaje no saben cómo ni dónde empezar.

## Objetivo General
Desarrollar una aplicación que permita la visualización de productos para maquillaje, para recomendar sugerencias al usuario.

## Objetivos Específicos
- Crear una interfaz que permita al usuario visualizar los productos y su información, de forma entendible y amigable.
- Añadir un catálogo de favoritos del usuario para propiciar sugerencias de estilo de maquillaje.
- Hacer una categorización en estilos de maquillaje para facilitar los resultados de las sugerencias.

## Tecnologías Utilizadas
- **Frontend:** Next.js
- **Backend:** Node.js con Prisma
- **Base de Datos:** PostgreSQL
